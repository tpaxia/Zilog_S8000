# Region map: start end kind [label]
#   kind = code | word | byte | string | msg
#     msg  = word length prefix followed by that many text bytes (routine 0x050c)
#     string = plain NUL-terminated text
# This overrides tools/trace.py, which only knows what control flow reaches.
# Anything not listed and not reached by the tracer falls back to .word data.

# The image ends with filler, not content.  The 26 zero bytes align the last
# routine up to a 256-byte boundary; everything above that is erased EPROM and
# is supplied by the build, so the source can grow into it.
0x32e6 0x3300 fill
0x3300 0x4000 blank

# Code the tracer cannot reach because the entry address is only known at run
# time.  Each range decodes with no undefined opcodes and its last instruction
# ends exactly on the boundary; tools/trace.py:linear() rechecks both on every
# build, so a wrong boundary fails loudly rather than emitting nonsense.

# Operands that are addresses, not constants.
#
# Outside branches and pointer tables, an operand falling inside the ROM may be
# an address or an ordinary number, and nothing in the encoding says which.
# Guessing wrong is worse than leaving hex: naming a constant means the constant
# silently changes if code ahead of it moves.  So tools/gen.py only symbolises
# what is listed here.
#
#   <instruction address> <operand value>   # why
#
# `make pointers` regenerates the provable subset (tools/pointers.py); this file
# is hand-maintained so that verified additions survive.

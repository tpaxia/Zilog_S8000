# ZEUS /dev device spec for the S8000 (SMD-based) machine.
# Format (mkdev):  <path> <c|b> <major> <minor> <octal-mode>
#
# Majors from the ZEUS kernel device switch (_cdevsw/_bdevsw):
#   char: 2=smd(raw)  6=mem/kmem/null  7=sys(/dev/tty)  8=sio(console/tty)
#   block: 0=zd  8=smd
# Char device numbers (console/tty/mem) verified against the working WEGA
# disk (harddisk.wdc). Disk devices use SMD (8/2), NOT WEGA's WDC/zd (0).
# console is (8,1) == tty1 (the SIO channel 1).

/dev/console c 8 1 622

# ---------------------------------------------------------------------------
# Nodes recovered from the pristine 1991-11-18 level-0 root dump
# (0-dump-911118-root.backup).  Numbers are exactly as recorded in that
# machine's on-disk inodes, not reconstructed.  The dump carried several of
# these as hard links to one inode (rct0/dumpdev/resdev share tardev's inode,
# zd1 shares swap's); mkdev has no link support, so they are created here as
# separate inodes with identical major/minor, which the kernel treats the same.
#
# None of these is opened by the Model 31 boot path -- init, rc, rc_csh and
# mfs use only root/usr/tmp/z/console/tty*.  They are present for fidelity and
# for tools that default to them (tar -> /dev/tardev, dump -> /dev/dumpdev,
# restor -> /dev/resdev).
# ---------------------------------------------------------------------------

# Cartridge tape, major 1.  Minors 0-3 select the drive/density, 4 is the
# default unit; +128 is the no-rewind variant.  The S8000 MAME machine has no
# cartridge-tape hardware, so these open with an error.

# WARNING -- the dump machine reached its disks through the zd driver
# (block major 0, raw char major 32).  This image is SMD: the working disk
# nodes are the smd/rsmd set above (block 8, char 2).  These zd nodes name the
# same partitions but route through a controller the S8000 MAME machine does
# not emulate.  They are recorded for fidelity only.  Do NOT fsck, mount or
# dd through them -- use /dev/root, /dev/usr, /dev/tmp, /dev/z instead.
